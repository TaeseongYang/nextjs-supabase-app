## 1. 문제 (Problem)

**해결하려는 핵심 문제 3가지**

1. **분산된 모임 운영 도구**
   - 일정은 카카오톡, 참여자 명단은 엑셀, 카풀 조율은 구두 전달로 분산되어 관리가 비효율적

2. **참여자 접근 장벽**
   - 앱 설치 없이 모임에 참여할 수 있는 방법이 없어 진입 장벽이 높음

3. **정산 분쟁 및 불투명성**
   - 모임 비용을 카카오페이 요청/구두로 관리해 입금 여부 추적이 어렵고 분쟁 발생

**기존 대안**

- 카카오톡 단체채팅 + 엑셀 조합
- 네이버 폼 + 수동 정산
- 구글 시트 공유

---

## 2. 고객 세그먼트 (Customer Segments)

**주 타겟: 주최자**

- 수영, 헬스, 테니스, 등산 등 정기 모임을 운영하는 20~30대 직장인
- 5~30명 규모 소그룹 모임 주최 경험 보유
- 반복적으로 같은 멤버와 모임을 이어가는 커뮤니티 리더

**부 타겟: 참여자**

- 주최자의 초대 링크로 접근하는 비회원
- 앱 설치 없이 빠르게 참여 등록을 원하는 일반인

**얼리 어답터**

- 매달 정기 모임을 운영하는 동호회 운영진
- 카카오톡으로 관리 한계를 느끼고 있는 소규모 커뮤니티 주최자

---

## 3. 가치 제안 (Unique Value Proposition)

**핵심 메시지**

> **"초대 링크 하나로 모임의 모든 것을 — 참여자, 카풀, 정산까지 한 곳에서"**

**차별화 포인트**

- 참여자는 앱 설치·회원가입 없이 링크 하나로 즉시 참여
- 주최자는 하나의 페이지에서 공지/참여자/카풀/정산을 탭으로 통합 관리
- 카카오톡 미리보기 최적화된 초대 링크 공유

---

## 4. 해결책 (Solution)

**핵심 기능 3가지**

1. **초대 링크 기반 비회원 참여 (F002, F003)**
   - 고유 토큰 URL 생성 → 이름+연락처 입력만으로 참여 완료
   - 최대 인원 초과 시 대기자 명단 자동 전환

2. **통합 이벤트 관리 대시보드 (F001, F004, F005)**
   - 공지/참여자/카풀/정산 탭 한 화면에서 전환 관리
   - 이벤트 상태 관리 (모집 중 → 확정 → 완료)

3. **카풀 조율 + 정산 트래킹 (F006, F007)**
   - 드라이버 등록 → 동승 신청 → 주최자 확정 워크플로우
   - 비용 1/n 또는 개별 분담, 입금 체크박스로 정산 현황 요약

---

## 5. 경쟁우위 (Unfair Advantage)

**쉽게 복사할 수 없는 강점**

- **비회원 참여 UX**: 앱/회원가입 없는 참여 경험은 기존 모임 관리 툴에서 제공하지 않음
- **모임 특화 올인원**: 일정·참여자·카풀·정산을 하나의 이벤트에 묶은 통합 구조
- **카카오톡 공유 최적화**: 한국 모임 문화에 맞는 공유 채널 최적화
- **초기 커뮤니티 네트워크**: 얼리 어답터 동호회 운영진 확보 시 입소문 전파

---

## 6. 수익 흐름 (Revenue Stream)

**MVP 단계 (현재)**

- 무료 제공 — 사용자 확보 및 제품-시장 적합성(PMF) 검증 단계

**Post-MVP 수익 모델 (검토)**

- **프리미엄 플랜**: 이벤트 무제한 생성, 고급 정산 기능, 참여자 내보내기(CSV)
- **팀/단체 플랜**: 여러 주최자가 같은 조직 이벤트를 공동 관리
- **연동 수수료**: 간편결제 연동 시 정산 처리 수수료 (카카오페이, 토스)

---

## 7. 비용 구조 (Cost Structure)

**고정 비용**

- Supabase 호스팅 (Free tier → Pro: $25/월)
- Vercel 배포 (Hobby 무료 → Pro: $20/월)
- 도메인 비용 (~$15/년)

**변동 비용**

- Supabase DB 스토리지 및 API 요청 (사용량 기반)
- 카카오 공유 API (무료 범위 내)

**개발 비용**

- 1인 개발 (기회비용)

---

## 8. 주요 지표 (Key Metrics)

**Acquisition (획득)**

- 신규 주최자 가입 수 (주간)
- 초대 링크 클릭 수

**Activation (활성화)**

- 이벤트 생성 완료율 (가입 후 첫 이벤트 생성 비율)
- 참여자 등록 전환율 (링크 클릭 → 참여 완료)

**Retention (유지)**

- 월 활성 주최자 수 (MAU)
- 주최자 1인당 월평균 이벤트 생성 수

**Revenue (수익)**

- (MVP 이후) 유료 전환율

**Referral (추천)**

- 이벤트당 평균 초대 링크 공유 수
- 참여자 → 주최자 전환율

# 모임 이벤트 관리 웹 MVP PRD

## 핵심 정보

**목적**: 카카오톡, 엑셀, 구두 전달로 분산된 모임 운영(일정, 참여자, 카풀, 정산)을 초대 링크 하나로 통합 관리
**사용자**: 주최자 — 수영/헬스/친구 모임을 운영하는 20~30대 직장인 (회원가입 필요) / 참여자 — 초대 링크로 접근하는 비회원

---

## 사용자 여정

```
1. [랜딩 페이지]
   ↓ "시작하기" 버튼 클릭

2. [회원가입 페이지] 또는 [로그인 페이지]
   ↓ 인증 완료

3. [주최자 대시보드]
   ↓ "이벤트 만들기" 클릭

4. [이벤트 생성 페이지]
   ↓ 이벤트 저장 완료

5. [이벤트 상세 페이지 - 주최자]
   ↓ 초대 링크 복사 → 카카오톡 공유

   --- 참여자 여정 분기 ---

6. 참여자가 링크 클릭 →

   [참여자 진입 페이지 (초대 링크)]
   ↓ 이름 + 연락처 입력 후 참여 완료

   [조건 A: 카풀 신청] → [카풀 신청 페이지] → 신청 완료
   [조건 B: 정산 확인] → [정산 내역 페이지] → 내역 확인

   --- 주최자 관리 여정 ---

7. [이벤트 상세 페이지 - 주최자] (탭 전환)
   ├── 공지 탭: 공지사항 작성/수정
   ├── 참여자 탭: 참여자 목록/상태 확인
   ├── 카풀 탭: 드라이버 등록/매칭 확정
   └── 정산 탭: 비용 항목 추가/입금 체크

8. [완료] → 대시보드로 복귀
```

## 기능 명세

### 1. MVP 핵심 기능

| ID       | 기능명           | 설명                                                                                      | MVP 필수 이유                                    | 관련 페이지                                                |
| -------- | ---------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
| **F001** | 이벤트 생성/관리 | 이벤트 CRUD, 상태 관리 (모집 중/확정/완료/취소)                                           | 서비스의 핵심 단위 — 모든 기능이 이벤트에 종속됨 | 이벤트 생성 페이지, 이벤트 수정 페이지, 이벤트 상세 페이지 |
| **F002** | 초대 링크 생성   | 고유 토큰 기반 초대 링크 생성 및 카카오톡 미리보기 공유                                   | 참여자가 앱 설치 없이 접근하는 유일한 진입 경로  | 이벤트 상세 페이지                                         |
| **F003** | 참여자 등록      | 비회원 참여자가 이름 + 연락처 입력으로 참여 완료, 최대 인원 초과 시 대기자 명단 자동 전환 | 비회원 참여 방식이 핵심 차별점                   | 참여자 진입 페이지                                         |
| **F004** | 참여자 현황 관리 | 참석/불참/미정/대기 상태 표시, 참여자 목록 및 인원 현황                                   | 주최자가 모임 규모를 파악하는 필수 정보          | 이벤트 상세 페이지                                         |
| **F005** | 공지사항         | 이벤트 페이지 상단 고정 공지 작성/수정                                                    | 주최자가 참여자에게 공지를 전달하는 핵심 채널    | 이벤트 상세 페이지, 참여자 진입 페이지                     |
| **F006** | 카풀 조율        | 드라이버 등록, 동승 신청, 주최자 확정, 카풀 현황 테이블                                   | 운동 모임 특성상 이동 조율이 필수                | 이벤트 상세 페이지, 카풀 신청 페이지                       |
| **F007** | 정산 트래킹      | 비용 항목 추가, 1/n 또는 개별 지정 분담, 입금 체크, 정산 현황 요약                        | 모임 비용 분담 투명화 — 정산 분쟁 방지           | 이벤트 상세 페이지, 정산 내역 페이지                       |

### 2. MVP 필수 지원 기능

| ID       | 기능명          | 설명                             | MVP 필수 이유                               | 관련 페이지                    |
| -------- | --------------- | -------------------------------- | ------------------------------------------- | ------------------------------ |
| **F010** | 주최자 인증     | 이메일 회원가입/로그인/로그아웃  | 이벤트 관리 권한 제어를 위한 최소 인증      | 로그인 페이지, 회원가입 페이지 |
| **F011** | 주최자 대시보드 | 내 이벤트 목록 조회 및 상태 필터 | 주최자가 모든 이벤트를 한눈에 관리하는 허브 | 주최자 대시보드                |

### 3. MVP 이후 기능 (제외)

- 소셜 로그인 (카카오, 구글)
- 프로필 상세 관리 (아바타, 자기소개)
- 실시간 알림 시스템
- 이벤트 댓글/채팅
- 반복 이벤트 (정기 모임)
- 참여자 앱 계정 생성

```

├── 랜딩 페이지 (홈)
├── 로그인 - F010

[주최자 메뉴 (로그인 후)]
├── 대시보드 - F011 (내 이벤트 목록)

└── 로그아웃

[이벤트 상세 탭 메뉴 (주최자)]
├── 공지 탭 - F005 (공지사항 작성/수정)
├── 참여자 탭 - F004 (참여자 목록/상태 관리)
├── 카풀 탭 - F006 (드라이버 등록/매칭)
└── 정산 탭 - F007 (비용 항목/입금 체크)

[참여자 메뉴 (비회원, 초대 링크 접근)]
├── 참여자 진입 페이지 - F003, F005 (참여 등록 + 공지 확인)
├── 카풀 신청 페이지 - F006 (드라이버 신청)
└── 정산 내역 페이지 - F007 (본인 정산 확인)
```

| **사용자 행동** | 이벤트 정보 확인, 이름과 연락처 입력, 참석 여부 선택 후 참여 완료                                                                                                                                                                                                                                                                        |
| **주요 기능**   | - 이벤트 기본 정보 표시 (제목, 날짜, 장소, 현재 참여 인원/최대 인원)<br>- 고정 공지사항 표시 (F005)<br>- 이름 입력 (필수), 연락처 입력 (선택)<br>- 참석/불참/미정 상태 선택<br>- 최대 인원 초과 시 대기자 안내 메시지 및 대기자 등록 처리 (F003)<br>- **"참여하기"** 버튼<br>- 참여 완료 후 카풀 신청 페이지, 정산 내역 페이지 링크 표시 |
| **다음 이동**   | 참여 완료 → 동일 페이지에 완료 메시지 + 카풀/정산 링크 표시, 유효하지 않은 토큰 → 에러 페이지                                                                                                                                                                                                                                            |
